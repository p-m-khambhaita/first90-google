# UX Flows

This document defines the key user flows for First90. Each flow describes the screens involved, what the user does, and what happens in the background. These flows inform the MVD screen list and the Expo Router navigation structure.

---

## Flow 1 — Onboarding & Role Setup

**Entry point:** Fresh install, no existing account.

**Goal:** Get the user from zero to a personalised 30-60-90 plan in under 3 minutes.

### Screens

**Screen 1.1 — Welcome**
- Full-screen illustration + tagline: *"Your AI mentor for the first 90 days."*
- Single CTA: "Get started"
- No sign-in required yet (deferred auth)

**Screen 1.2 — Role Setup**
- Fields: Job title (free text), Company name (free text), Start date (date picker)
- Optional: Team / department (free text)
- CTA: "Build my plan"
- Behind the scenes: PathArchitect maps job title to closest archetype; no user action required

**Screen 1.3 — Plan Preview**
- Shows the generated Phase 1 plan: list of 6 goals with due dates
- User can swipe to dismiss any goal they feel is irrelevant (flagged as skipped, PathArchitect notes it)
- CTA: "This looks right" / "Let me adjust"
- "Let me adjust" opens a free-text field: "Anything specific you want to focus on?" — fed back into PathArchitect for a revised proposal

**Screen 1.4 — Check-in Frequency**
- "How often do you want to check in?"
- Options: Every evening / 3x a week / I'll check in when I want
- Sets push notification schedule

**Screen 1.5 — Sign in / Create account**
- Magic link (email) or Google OAuth
- Brief copy: "Save your plan and access it on any device."
- Skip option: "Not now" — data stored locally until sign-in

**Screen 1.6 — Ready**
- Confirmation: "Your first 90 days start now."
- Today's first micro-action (generated by ExperienceCoach)
- CTA: "Go to my plan"

## Flow 2 — Daily Check-in

**Entry point:** Push notification (evening) or tapping "Check in" on home screen.

**Goal:** Capture the user's day in under 60 seconds; generate a micro-action for tomorrow.

### Screens

**Screen 2.1 — Check-in Entry**
- Warm greeting (time-aware: "How did today go?" / "What happened today?")
- Confidence slider: 1–10 with emoji anchors (1 = 😓, 5 = 😐, 10 = 😄)
- Energy slider: 1–10
- Optional free text: "Anything specific?" (placeholder: "Good, bad, weird — whatever's on your mind")
- Tag picker: multi-select chips grouped by Feelings/Context (e.g. `meetings`, `deadlines`, `relationships`, `workload`, `learning`, `unclear_expectations`, `imposter_syndrome`, `win`) and Activities (e.g. `data_analysis`, `strategy`, `coding`, `client_calls`, `writing`, `process_improvement`, `people_interaction`, `financial_analysis`)
- CTA: "Done"

**Screen 2.2 — Micro-action Response**
- Appears immediately after submitting check-in
- Shows 1–3 micro-actions for tomorrow (ExperienceCoach output)
- Each action has: short title, 1-sentence explanation, Accept / Dismiss controls
- Accepted actions are added to tomorrow's task list
- "See your week" link takes user to Plan screen

**Screen 2.3 — Pattern insight (conditional)**
- Shown only when ExperienceCoach or SignalScout has a meaningful pattern to surface
- Plain prose: 2–3 sentences, warm tone
- Example: *"You've rated client calls as high-energy 4 times this week. That's worth noticing."*
- Dismiss or "Save this insight" (bookmarks to a notes section)

## Flow 3 — CommsCoach (On-demand)

**Entry point:** CommsCoach tab or "Get help with a message" shortcut on home screen.

**Goal:** Help the user rewrite a draft message in under 2 minutes.

### Screens

**Screen 3.1 — CommsCoach Home**
- Two entry points:
  - "Rewrite a message" — paste a draft
  - "Help me prepare for a conversation" — describe what you need to say
- Recent scripts section (last 3 CommsCoach outputs, tap to re-view)

**Screen 3.2 — Message Input**
- Large text field: "Paste your draft here"
- Below: Recipient context ("Who is this for?" — dropdown: Manager / Senior colleague / Peer / Client / Other)
- Goal field: "What do you want to happen?" (short free text)
- Tone preference: toggle between Professional-warm / Concise-direct / Senior-peer / Friendly-junior
- CTA: "Get rewrites"

**Screen 3.3 — Rewrite Results**
- Tab bar: Variant 1 / Variant 2 (MVD generates 2 variants; v0.2+ expands to 3)
- Each tab shows the rewritten message + expandable "Why these changes?" section
- Actions: Copy to clipboard / Share / Save to suggestions / Try a different tone
- Back: discard and start again

## Flow 4 — Explore & Fit-Check

**Entry point:** Explore tab (visible from Phase 2 onwards).

**Goal:** Help the user understand their emerging role-fit signals and take concrete exploration actions.

### Screens

**Screen 4.1 — Explore Home**
- Section: "Your fit signals so far" — top 3 archetypes with plain-language labels and a simple bar indicator
- Section: "Suggested explorations" — 2–3 specific actions based on current top archetype (e.g. "Shadow the data team this week")
- Section: "All archetypes" — full list, tappable

**Screen 4.2 — Archetype Detail**
- Archetype name, description, typical tasks
- Current fit signal for this user ("Strong" / "Emerging" / "Weak" / "No signal yet")
- Evidence: "Based on X check-ins and Y exploration activities"
- Suggested exploration activities for this archetype (tappable — adds to plan as a goal)
- "Not for me" button — dismisses archetype from explore feed for 14 days

**Screen 4.3 — Fit-Check Reflection (Day 45 / Day 90)**
- Triggered by SignalScout; appears as a card on home screen and as a full screen
- Shows ranked fit scores with plain-language labels
- Reflection prompt (2–3 questions): "What surprised you? What confirmed what you already suspected? What do you want to explore next?"
- Free text response (stored client-side in private mode; cloud with consent in standard mode)
- CTA: "Save my reflection" — stored in `suggestions` as `type: fit_check_reflection`

## Navigation Structure (Expo Router)

```
(tabs)/
  home.tsx          ← Home screen: phase banner, today's tasks, check-in prompt
  plan.tsx          ← 30-60-90 plan view with goals
  explore.tsx       ← Role fit signals and exploration (Phase 2+)
  comms.tsx         ← CommsCoach
  inbox.tsx         ← Suggestions inbox (all agent proposals)

(modals)/
  check-in.tsx      ← Daily check-in modal (fullscreen)
  archetype/[id].tsx ← Archetype detail modal
  fit-check.tsx     ← Fit-check reflection modal
  rewrite-result.tsx ← CommsCoach results

(onboarding)/
  welcome.tsx
  role-setup.tsx
  plan-preview.tsx
  frequency.tsx
  sign-in.tsx
  ready.tsx
```

## Design Principles for Flows

1. **Every flow has a clear end state.** The user knows when they're done.
2. **No flow should take more than 90 seconds.** Check-in, comms rewrite, exploration — all time-boxed by design.
3. **Agent outputs are always proposals.** No silent mutations. Every suggestion has Accept / Dismiss controls.
4. **Progressive disclosure.** Explore tab is hidden in Phase 1. Fit scores are not shown until Phase 2. Manager conversation prep is not surfaced until Phase 3.
5. **Warm, not clinical.** Microcopy should sound like a thoughtful colleague, not a corporate performance management tool.
